## Por que ele se atualiza sozinho

A ideia por trás do site é simples: eu não queria manter duas vidas em dia, a
do GitHub e a do portfólio. Então ele lê meus repositórios direto do GitHub.
Crio um projeto novo e ele aparece aqui por conta própria, com descrição,
linguagem e link, sem eu editar uma linha de código.
